# Mesto

Учебный проект ассоциированных программ Яндекса и СГУ.

Интерактивная страница, на которой пользователи могут делиться фотографиями мест. Проект подключён к API-серверу и поддерживает работу с данными в реальном времени.

## Функциональность

- Просмотр карточек мест, загруженных пользователями группы
- Добавление и удаление своих карточек
- Редактирование профиля и аватара
- Постановка и снятие лайков со счётчиком
- Просмотр статистики пользователей группы
- Просмотр информации о карточке

## Технологии

- HTML, CSS, JavaScript (ES6+)
- Vite
- REST API (fetch)
- GitHub Actions (CI/CD)
- GitHub Pages

## Команды
```bash
# Запуск локального сервера разработки
npm run dev

# Сборка проекта
npm run build

# Публикация на GitHub Pages
npm run deploy
```
